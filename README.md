# WhatsApp Appeal Assistant — Android

تطبيق أندرويد مستقل لإعداد طلب مراجعة لحظر حساب WhatsApp. الهدف أن تعمل الواجهة والقوالب وفحص الصور محليًا على جهاز المستخدم، دون رفع الصور أو الاعتماد على OCR server.

## الحالة الحالية

هذا المستودع بدأ بهيكل Android أصلي باستخدام Kotlin وJetpack Compose. محرك التحقق يُنقل تدريجيًا من مشروع البوت `atemmokhtar2-blip/wa-unban-bot`، مع الحفاظ على قواعد التحقق الصارمة وعدم قبول الصورة عند تعذر OCR.

## المتطلبات

- Android Studio حديث يدعم Android Gradle Plugin 8.7.3 وKotlin 2.0.21.
- JDK 17.
- اتصال إنترنت أثناء أول build لتنزيل اعتماديات Gradle وملفات Tesseract traineddata؛ بعد تضمينها في APK تتم قراءة الصور دون اتصال.

## البناء

افتح المستودع في Android Studio ثم نفّذ Sync وBuild. مهمة Gradle `downloadTessdata` تنزّل ملفات اللغة `eng` و`ara` إلى assets قبل بناء التطبيق. لا يتم تنزيل الصور أو إرسالها إلى خادم أثناء الاستخدام.

## الخصوصية

- OCR محلي باستخدام Tesseract.
- الصور لا تغادر الجهاز.
- لا يوجد backend أو API أو تسجيل دخول في النسخة الأولى.
- لا يتم إرسال طلب مراجعة تلقائيًا؛ التطبيق يجهّز النص ويترك للمستخدم مراجعته وإرساله.

## مراحل التنفيذ

1. تأسيس تطبيق Android وواجهة عربية RTL.
2. تضمين Tesseract وملفات اللغة العربية والإنجليزية داخل APK.
3. نقل قواعد التحقق من `screenshot_verifier.py` واختبار تطابقها.
4. نقل قوالب `templates.py` إلى Kotlin.
5. حفظ المسودات محليًا وتحسين تجربة التصدير والمشاركة.

> لا يضمن التطبيق استعادة الحساب؛ القرار النهائي يعود إلى WhatsApp.
