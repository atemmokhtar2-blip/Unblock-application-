# Unblock Assistant — Android

تطبيق أندرويد أصلي مستقل لمساعدة المستخدم على تجهيز طلب مراجعة لحساب WhatsApp مقيّد.

## المزايا

- واجهة عربية متدرجة خطوة بخطوة، مع شاشة افتتاحية سوداء متحركة.
- خط Alexandria عربي مضمّن داخل التطبيق.
- اختيار صورة إشعار الحظر وفحصها محليًا بمحرك Tesseract4Android (LSTM).
- نماذج OCR العربية والإنجليزية تُضمّن داخل APK أثناء البناء؛ لا تُرفع الصور إلى أي خادم.
- تجهيز مسودة بريد إلكتروني للمراجعة؛ المستخدم يراجعها ويضغط إرسال بنفسه.

## البناء

المتطلبات: JDK 17 وAndroid SDK 35.

```bash
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

مهمة Gradle `downloadAppAssets` تجهز نماذج OCR العربية والإنجليزية وخط Alexandria أثناء البناء. يحتاج أول بناء إلى اتصال إنترنت لتنزيل الملفات والاعتماديات. بعد تثبيت APK، يعمل فحص الصور دون اتصال.

GitHub Actions يشغّل اختبارات الوحدة ويبني Debug APK ويرفعه كـ artifact عند كل تحديث على `main`.

## الخصوصية والحدود

- لا يوجد خادم خارجي أو حساب سحابي.
- الصور تُقرأ وتُفحص محليًا على الهاتف.
- لا يستخدم التطبيق ذكاءً اصطناعيًا.
- فحص الصورة يعتمد OCR ومؤشرات نصية، وقد يرفض لقطة صحيحة إذا كانت غير واضحة.
- لا يضمن التطبيق استعادة الحساب؛ القرار النهائي لدى WhatsApp.
- لا يُرسل البريد تلقائيًا؛ المستخدم هو من يراجع الرسالة ويرسلها.
