# Unblock Assistant — Android

تطبيق أندرويد أصلي مستقل لمساعدة المستخدم على تجهيز طلب مراجعة لحساب WhatsApp مقيّد.

## ما يعمل محليًا

- واجهة عربية باستخدام Kotlin وJetpack Compose.
- اختيار صورة إشعار الحظر من الهاتف وفحصها محليًا باستخدام Tesseract OCR.
- نماذج OCR العربية والإنجليزية تُضمّن داخل APK أثناء البناء؛ لا يتم إرسال الصور إلى أي خادم.
- قواعد تحقق صارمة: حجم الصورة ودقتها ونسبة أبعادها ومحتواها، وضوح النص، اسم WhatsApp، إشارات الحظر، إشارات السياسات، واستبعاد المنصات الأخرى.
- استخراج بيانات ظاهرة في الإشعار عند توافرها: التاريخ، رقم الهاتف، نوع التقييد، وسبب/مؤشر السياسة.
- إنشاء مسودة خطاب كامل، أو نص قصير لطلب المراجعة داخل واتساب، أو نسخة عربية، أو متابعة بعد 48 ساعة، أو تصعيد، أو إشعار أخير.
- تدوير صيغ الخطاب الإنجليزية عبر متغيرات متعددة، مع إدراج الأدلة المستخرجة فقط عندما تكون متاحة.
- لا يتم إرسال الطلب تلقائيًا؛ المستخدم يراجع النص ويختار مشاركته بنفسه.

## البناء

المتطلبات: Android Studio حديث، JDK 17، وAndroid SDK 35.

من جذر المستودع:

```bash
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

مهمة Gradle `downloadTessdata` تنزّل نماذج `eng` و`ara` أثناء البناء. يحتاج أول build إلى اتصال إنترنت لتنزيل الاعتماديات والنماذج. بعد تثبيت APK، يعمل OCR دون اتصال.

GitHub Actions يبني Debug APK ويشغّل اختبارات القوالب تلقائيًا عند التحديث على `main`.

## الخصوصية والحدود

- لا يوجد backend أو تسجيل دخول أو قاعدة بيانات سحابية.
- صور المستخدم لا تغادر الجهاز ضمن مسار الفحص.
- لا يوجد ذكاء اصطناعي؛ الفحص يعتمد OCR وقواعد نصية ثابتة.
- نتيجة الفحص ليست ضمانًا لصحة الصورة بنسبة 100%؛ قد تُرفض لقطة صحيحة إذا كان النص غير واضح أو لا يطابق المؤشرات المحددة.
- لا يضمن التطبيق استعادة الحساب؛ WhatsApp وحده يقرر نتيجة المراجعة.
- لا تُضاف أي ادعاءات عن نشاط الحساب إلى الرسالة إلا إذا كانت بيانات الإشعار نفسها تدعمها.
